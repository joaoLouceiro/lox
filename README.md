# lox
A scripting language from Robert Nystrom's book, "Crafting Interpreters".

There are two main components to the project: *jlox* and *clox*.

## jlox
`jlox` is a Java based Tree-Walk interpreter for lox. This type of interpreter and the choice of language make it a simple enough introduction to the topic of compilers and interpreters, without getting lost in the intricacies of bytecode generation, memory management, and overall low-level mumbo-jumbo.

## clox
`clox` is a bytecode compiler built in C. That's all I can say for now.
